# BestellAPP

Responsive Bestell-App für ein Restaurant.

## Features

- Menü-Anzeige mit Kategorien (Burger, Pizza, Salate)
- Warenkorb-Funktion (Hinzufügen, Entfernen, Mengen ändern)
- Responsive Design (Desktop + Mobile)
- Moderne UI mit eigenen Icons und Bildern

## Tech Stack

- HTML5
- CSS3 (inkl. responsive Styles)
- Vanilla JavaScript

## Installation & Nutzung

1. Repository klonen
2. `index.html` im Browser öffnen

Keine Build-Tools oder Dependencies erforderlich.
